概念与架构

问题加分要点
K8s 是什么 / 解决什么问题四个问题：放哪（调度）、怎么找到（Service）、坏了怎么办（控制循环）、流量变化（扩缩）；贯穿设计是声明式
和 Docker 的关系分层：OCI 镜像标准 / 运行时（CRI）/ 编排；DockerShim 移除的是适配层不是兼容性
架构与组件职责决策层 vs 执行层；只有 apiserver 写 etcd；组件靠 watch 协作不直接通信
某组件挂了会怎样控制平面故障影响「未来变更」，数据路径与已运行负载短期不受影响；etcd 是唯一真单点风险
kube-proxy 怎么转发不转发：维护 iptables/IPVS 规则，数据路径在内核；所以它挂了存量连接大多照常
为什么只有 apiserver 能碰 etcd单一写入口才有统一的认证、审计、watch 通知；etcd 不承载业务语义

Pod 生命周期

问题加分要点
apply 到 Ready 的完整流程九站链（第 03 章）；准入 mutating 先于 validating；scheduler 只 bind；CNI 在沙箱创建时配 IP；EndpointSlice 收尾
三种探针区别liveness 管生死（失败重启）、readiness 管流量（失败摘除）、startup 管慢启动；readiness 失败不重启
优雅终止过程从 EndpointSlice 摘除 → SIGTERM → preStop → 宽限期（默认 30s）→ SIGKILL；摘除与杀进程是并行的，所以可能有短暂流量损失
容器崩溃重启走调度吗不走：kubelet/运行时按 restartPolicy 本地重启；Pod 对象重建才重走全流程
CrashLoopBackOff 怎么排查退出码定性（137=OOM）→ logs -p → lastState.terminated → 必要时 kubectl debug

工作负载与网络

问题加分要点
Deployment 滚动更新新 ReplicaSet + 交替伸缩；maxSurge/maxUnavailable 计算；旧 RS 保留所以回滚快
StatefulSet 三个稳定网络标识、存储（volumeClaimTemplates）、有序部署；数据复制仍是应用职责
Service 四种类型叠加关系：ClusterIP → NodePort → LoadBalancer；ExternalName 是 CNAME；headless 直接返回 Pod IP
ClusterIP 本质虚拟 IP，只存在于内核规则；无网卡持有
DNS 解析链路svc.ns.svc.cluster.local；普通 Service 解析到 ClusterIP，headless 到 Pod IP；ndots 导致的解析顺序坑
Ingress 与 Service 区别七层 vs 四层；Ingress 对象是规则、控制器是执行者；控制器常经 LoadBalancer Service 暴露

资源、存储、安全

问题加分要点
requests / limits 区别调度账面 vs 上限；CPU 超限节流、内存超限 OOM；QoS 三档决定驱逐顺序
Eviction 与 OOM Kill 区别节点级压力取舍 vs 单容器超自身 limit
污点与容忍节点拒客视角；三种 effect；节点故障靠 NoExecute 污点驱赶 Pod
PV/PVC/StorageClass供需两侧 + 创建配方；Delete 回收策略 = 删 PVC 即删数据
ConfigMap 热更新volume 会更新（有延迟）、env 不更新、subPath 不更新；应用还要自己 reload
Secret 安全吗base64 非加密；真安全 = RBAC + etcd 静态加密 + 传输 TLS
RBAC 四件套Role/ClusterRole 是规则集，Binding 连主体；kubectl auth can-i 验证
给 Pod 最小权限专属 SA → 零权限起步 → 按需 Role → RoleBinding（非 Cluster）；不需要就关 automount
Namespace 是安全边界吗不是：网络默认全通；隔离要 NetworkPolicy + RBAC + PSA

扩展与运维

问题加分要点
什么是 OperatorCRD + 控制器；把运维知识编码成调谐循环；与内置控制器同机制
Informer 原理List-Watch + 本地缓存；读缓存写 API；WorkQueue 去重限速；watch 是推送不是轮询
准入 Webhookmutating 可改写、validating 只裁决；顺序上 mutating 在前
HPA 原理metrics-server 供指标；desired = ceil(current × desiredMetric/currentMetric)；受同步周期与稳定窗口影响
节点 NotReady 排查describe node 压力条件 → kubelet 日志 → 磁盘/网络插件；宽限期后 Pod 被重建

陷阱题清单（答错即减分）

  • 「kube-proxy 把流量代理到 Pod」→ 它不在数据路径上
  • 「apply 成功就是部署成功」→ 只完成了落库，后面全异步
  • 「Service 里存着 Pod 列表」→ 存的是选择器；列表在 EndpointSlice
  • 「readiness 失败会重启容器」→ 只会摘流量；重启是 liveness 的事
  • 「Secret 是加密的」→ base64 编码
  • 「Namespace 默认隔离」→ 默认全通
  • 「scheduler 启动容器」→ 只写 nodeName
  • 「K8s 移除 Docker 支持 = 不兼容 Docker」→ 移除的是 DockerShim，镜像照跑
  • 「StatefulSet 自动数据高可用」→ 只保证盘跟着 Pod 走
  • 「写了 CRD 就有功能」→ 没有控制器什么都不会发生
