术语对照表

中英对照，跟随中文社区实际语感。括号内为英文原文或社区惯用写法。

使用约定

三档处理：中文为主（节点 Node、调度器 Scheduler）；英文为主（Pod、Deployment、Service——社区不说「容器组」「部署对象」）；组件名直接用英文（kubelet、etcd、kube-proxy）。

核心概念

英文中文 / 惯用一句话
Cluster集群一组被 K8s 统一管理的机器
Node节点集群中的一台工作机器（旧称 minion）
Control Plane控制平面做决定的组件集合（旧称 master）
PodPod（官方译「容器组」，社区不用）最小调度单元，共享网络/存储的容器组
Workload工作负载「怎么跑容器」的对象族
Namespace命名空间名字与配额的作用域
Label / Selector标签 / 选择器K8s 的通用组织与匹配机制
Annotation注解附带元信息，不参与选择
Desired State / Actual State期望状态 / 实际状态spec 与 status 所记录的两侧

Declarative / Imperative声明式 / 命令式描述结果 vs 描述步骤
Eventually Consistent最终一致变更异步生效，状态持续逼近

标准接口

英文管什么
CRI（Container Runtime Interface）K8s ↔ 容器运行时
CNI（Container Network Interface）Pod 网络：IP 分配、连通、NetworkPolicy 执行
CSI（Container Storage Interface）存储卷的供给与挂载

状态词

状态含义
Pending已受理未就绪：多在等调度或等镜像
Running至少一个容器在运行（不代表可用）
Succeeded / Failed全部容器正常退出 / 有容器失败退出
CrashLoopBackOff反复崩溃重启，退避间隔递增
ImagePullBackOff镜像拉取失败重试中
ContainerCreating沙箱/镜像/卷准备中
Terminating终止流程中（优雅终止或 finalizer 未清）
Evicted被节点驱逐
NotReady（Node）节点失联或不健康
